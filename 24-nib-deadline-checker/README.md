# NIB Deadline Checker

Cek tenggat kewajiban NIB untuk pedagang marketplace berdasarkan Permendag 19/2026 (berlaku 8 Juni 2026).

## Run

```bash
python server.py
```

Buka http://localhost:8024

Masukkan tanggal mulai jualan, tool menghitung tenggat NIB (18 bulan untuk seller existing, 6 bulan untuk seller baru), sisa hari, dan status risiko. Lengkap dengan checklist dokumen, langkah buat NIB via OSS, dan klarifikasi NIB vs pajak.
