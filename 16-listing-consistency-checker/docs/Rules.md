# Rules

## Coding Standards
- No em dashes anywhere
- No emoji in buttons/titles
- Inline CSS only, no Tailwind CDN
- Light theme default (#fafafa bg)
- Responsive required (@media max-width:768px)

## Git
- Separate commits per logical change
- No security details in commit messages
- Push after each fix

## Testing
- curl all API endpoints
- Verify HTML has @media query
- Verify HTML has #fafafa
- grep for em dashes before commit

## Banned
- Dark theme as default
- Tech blue/purple accents
- Glassmorphism, gradients
- Tutorial/how-to sections
- Footer text
- Badge spam
