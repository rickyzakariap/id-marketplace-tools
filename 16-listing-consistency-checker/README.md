# Listing Consistency Checker

Check if your product listings are consistent across marketplaces. Compare price, title, and stock to spot discrepancies.

## Run

```
npm install
node server.js
```

Open http://localhost:3616

## Features

- Add listings per marketplace (Tokopedia, Shopee, Lazada, Bukalapak, Blibli, TikTok Shop)
- Group listings by product name
- Consistency score per product (0-100%)
- Visual diff: mismatches highlighted in red
- Price outlier detection
- Dark/light theme toggle
- Responsive design
